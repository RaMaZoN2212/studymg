# 🚀 Быстрый старт StudyMG

## За 3 минуты до запуска!

### 1️⃣ Установите зависимости

```bash
cd studymg
flutter pub get
```

### 2️⃣ Запустите приложение

Выберите платформу:

**Для Web (Chrome):**
```bash
flutter run -d chrome
```

**Для Android:**
```bash
flutter run -d android
```

**Для iOS:**
```bash
flutter run -d ios
```

**Для Desktop:**
```bash
flutter run -d linux    # или windows, или macos
```

### 3️⃣ Готово! 🎉

Приложение запустится автоматически.

## 📱 Первые шаги

1. **Добавьте курс**
   - Нажмите на вкладку "Курсы"
   - Нажмите кнопку "+" внизу справа
   - Заполните информацию
   - Выберите дни недели
   - Нажмите "Создать курс"

2. **Добавьте задание**
   - Перейдите на вкладку "Задания"
   - Нажмите "+" внизу справа
   - Выберите курс
   - Введите название
   - Выберите срок
   - Нажмите "Создать задание"

3. **Посмотрите формулы**
   - Откройте вкладку "Формулы"
   - Выберите Математика или Физика
   - Просматривайте формулы

## ❓ Проблемы?

1. Выполните `flutter doctor` для проверки установки
2. Убедитесь, что Flutter версии 3.0+
3. Попробуйте `flutter clean` и пересоберите

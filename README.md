## 🎯 Особенности реализации

### Умное отображение формул
Приложение автоматически выбирает лучший способ отображения для каждой формулы:
- **Короткие** (< 80% ширины) → Нормальный размер, по центру
- **Средние** (80-120%) → Уменьшенный размер
- **Длинные** (120-150%) → Сильно уменьшенный
- **Очень длинные** (> 150%) → Горизонтальная прокрутка с подсказкой

### Локальное хранилище
Все данные сохраняются локально с помощью Hive:
- Курсы и расписание
- Домашние задания
- Избранные формулы
- Работает без интернета

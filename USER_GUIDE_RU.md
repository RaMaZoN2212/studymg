# Руководство пользователя StudyMG

## 📱 Добро пожаловать в StudyMG!

StudyMG - это ваш персональный помощник в организации учебного процесса. Это приложение поможет вам управлять курсами, отслеживать домашние задания и быстро находить нужные формулы.

## 🎯 Быстрый старт

### Первый запуск

При первом запуске приложения вы увидите три основных раздела:

1. **Курсы** - управление вашими учебными курсами
2. **Задания** - отслеживание домашних заданий
3. **Формулы** - справочник математических и физических формул

## 📚 Работа с курсами

### Как добавить курс

1. Откройте вкладку **"Курсы"** внизу экрана
2. Нажмите на кнопку **"Добавить курс"** (плавающая кнопка с +)
3. Заполните обязательные поля:
   - **Название курса** - например, "Математика" или "Физика"
   - **Дни недели** - выберите дни, когда проходят занятия

4. Дополнительно можете указать:
   - **Описание** - краткое описание курса
   - **Преподаватель** - имя преподавателя
   - **Аудитория** - номер кабинета или аудитории
   - **Время** - время начала занятий (например, "10:00 - 11:30")
   - **Цвет** - выберите цвет для визуального различения курсов

5. Нажмите **"Создать курс"**

### Просмотр деталей курса

- Нажмите на любой курс в списке
- Вы увидите подробную информацию о курсе
- Внизу отображаются все домашние задания для этого курса

### Редактирование курса

1. Откройте детали курса
2. Нажмите на иконку **редактирования** (карандаш) в правом верхнем углу
3. Внесите изменения
4. Нажмите **"Сохранить изменения"**

### Удаление курса

1. Откройте детали курса
2. Нажмите на иконку **удаления** (корзина) в правом верхнем углу
3. Подтвердите удаление

⚠️ **Внимание**: При удалении курса все связанные домашние задания сохранятся

## ✅ Управление домашними заданиями

### Как добавить задание

1. Откройте вкладку **"Задания"**
2. Нажмите на кнопку **"Добавить задание"**
3. Заполните форму:
   - **Курс** - выберите курс из списка
   - **Название задания** - например, "Решить задачи 1-10"
   - **Описание** (опционально) - дополнительные детали
   - **Срок сдачи** - по умолчанию устанавливается дата следующего занятия

4. Нажмите **"Создать задание"**

### Работа с заданиями

**Отметить как выполненное:**
- Нажмите на чекбокс слева от задания
- Или нажмите на само задание

**Редактирование:**
- Проведите пальцем влево по заданию
- Нажмите синюю кнопку **"Изменить"**

**Удаление:**
- Проведите пальцем влево по заданию
- Нажмите красную кнопку **"Удалить"**

### Фильтрация заданий

На экране заданий есть две вкладки:

- **Активные** - незавершённые задания, отсортированные по срокам
- **Выполненные** - завершённые задания

### Индикаторы срочности

Задания отображаются с цветовыми индикаторами:

- 🔴 **Красный** - просроченные задания
- 🟠 **Оранжевый** - срок истекает сегодня или завтра
- ⚪ **Обычный** - до срока ещё есть время

## 🧮 Справочник формул

### Математические формулы

Вкладка **"Математика"** содержит:
- Теорема Пифагора
- Решение квадратных уравнений
- Формулы площади и объёма
- Тригонометрические формулы
- Формулы прогрессий
- И многое другое...

### Физические формулы

Вкладка **"Физика"** содержит:
- Законы Ньютона
- Законы сохранения энергии
- Электричество (закон Ома, мощность)
- Кинематика
- Волны и оптика
- И многое другое...

### Как пользоваться

1. Откройте вкладку **"Формулы"**
2. Выберите категорию (Математика или Физика)
3. Просматривайте формулы с их описаниями
4. Формулы отображаются в математической нотации для лучшего понимания

## 🎨 Персонализация

### Цвета курсов

Каждому курсу можно назначить свой цвет из 10 доступных вариантов. Это помогает:
- Быстро находить нужный курс
- Легко различать задания разных курсов
- Делать интерфейс более наглядным

### Тёмная тема

Приложение автоматически переключается между светлой и тёмной темой в зависимости от системных настроек вашего устройства.

## 💡 Полезные советы

### Организация курсов

1. **Используйте описания** - добавляйте важную информацию о курсе
2. **Указывайте время** - это поможет не забыть о занятиях
3. **Выбирайте разные цвета** - для лучшей визуальной навигации

### Работа с заданиями

1. **Добавляйте задания сразу** - не откладывайте на потом
2. **Используйте описания** - записывайте детали задания
3. **Проверяйте активные задания** - регулярно просматривайте список
4. **Отмечайте выполненные** - это мотивирует!

### Использование формул

1. **Добавьте в закладки** - часто используемые формулы легко найти
2. **Читайте описания** - они помогают понять применение формулы
3. **Используйте во время учёбы** - быстрый доступ к справочнику

## 🔒 Безопасность данных

### Локальное хранение

- Все ваши данные хранятся **только на вашем устройстве**
- Приложению **не требуется интернет** для работы
- Никакие данные **не отправляются** на внешние серверы

### Резервное копирование

⚠️ **Важно**: Поскольку данные хранятся локально, рекомендуется:
- Регулярно делать резервные копии устройства
- При переустановке приложения данные будут удалены

## ❓ Часто задаваемые вопросы

**Q: Можно ли использовать приложение без интернета?**  
A: Да! Приложение полностью работает офлайн.

**Q: Синхронизируются ли данные между устройствами?**  
A: Нет, данные хранятся только локально на текущем устройстве.

**Q: Можно ли добавить свои формулы?**  
A: В текущей версии доступны только предустановленные формулы.

**Q: Что произойдёт с заданиями при удалении курса?**  
A: Задания сохранятся в списке, но не будут связаны с курсом.

**Q: Как изменить срок сдачи задания?**  
A: Откройте задание для редактирования и выберите новую дату.
